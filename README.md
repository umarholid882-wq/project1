# "Тасма" — Заманбап Кинотеатрдын прототиби

Бул долбоор — кинотеатрдын веб-сайтынын толук кандуу иштеген прототиби. Долбоор таза HTML, CSS жана Vanilla JavaScript колдонуу менен, эч кандай фреймворксуз жазылган.

## Мүмкүнчүлүктөрү:
1. **Афиша жана Жакында чыга турган тасмалар**: Тасмалардын сүрөтү, жанры, узактыгы жана маалыматы.
2. **Сеанстарды чыпкалоо**: Күнү жана тасмасы боюнча сеанстарды тандоо.
3. **Билет брондоо (Интерактивдүү зал)**: 
   - Залдагы бош/ээленген орундарды көрүү.
   - Орундуктарды тандоо.
   - Билеттин санын жана жалпы сумманы динамикалык түрдө эсептөө.
4. **Трейлер көрүү**: Модалдык терезеде YouTube аркылуу трейлер ачуу.
5. **Пикирлер жана баалоо**: Колдонуучулардын пикирлерин `localStorage` аркылуу сактоо.
6. **Алдын ала буйрутма**: Жакында чыга турган тасмаларга алдын ала заказ берүү.
7. **Кошумча**: Издөө, эскертмелер (Toast) жана "Өйдө чыгуу" баскычы.

## Иштетүү:
1. Бардык файлдарды бир папкага чыгарыңыз.
2. `index.html` файлын каалаган заманбап браузерде ачыңыз. (Сервер талап кылынбайт, бардыгы локалдуу иштейт).
